# CSLAV_OCR — Оптическое распознавание церковнославянских текстов

Проект предназначен для распознавания церковнославянских текстов из изображений и PDF-файлов с использованием нейронной сети.

## 📋 Описание

CSLAV_OCR распознает древние церковнославянские буквы, включая:
- Основную кириллическую азбуку (а, б, в, г, д, е, ж, з, и, к, л, м, н, о, п, р, с, т, у, ф, х, ц, ч, ш, щ, ъ, ь, ю)
- Старославянские буквы (ꙁ, ѕ, і, ѡ, ѣ, ѧ, ѳ, ѵ, ꙋ, ꙗ, ᲂ)
- Диакритические знаки (҆, ́, ̾, ҇, ̀, ҃, ⷮ, ⷣ)
- Знаки препинания (., ,)

Модель обучена на изображениях из Евангелия 1606 года и поддерживает 49 классов символов.

## 🔧 Требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)

Для работы приложения необходимы следующие библиотеки:

```
numpy>=1.21.0
opencv-python>=4.5.0
tensorflow>=2.16.0
PyMuPDF>=1.19.0  # для работы с PDF
```

**Важно:** В версиях TensorFlow >= 2.11 модуль `keras` встроен непосредственно в `tensorflow`, поэтому отдельная установка `keras` не требуется и может вызвать конфликты импорта.

## 📦 Установка

### 1. Клонируйте репозиторий (если еще не сделали)

```bash
cd CSLAV_OCR-main
```

### 2. Создайте виртуальное окружение (рекомендуется)

```bash
python -m venv venv
```

### 3. Активируйте виртуальное окружение

**Windows:**
```bash
venv\Scripts\activate
```

**Linux/macOS:**
```bash
source venv/bin/activate
```

### 4. Установите зависимости

```bash
pip install -r requirements.txt
```

Или установите пакеты вручную:
```bash
pip install numpy opencv-python tensorflow PyMuPDF
```

## 🚀 Запуск приложения

### Вариант 1: Графический интерфейс (РЕКОМЕНДУЕТСЯ)

Для удобной работы с приложением через графический интерфейс:

```bash
python gui_app.py
```

**Возможности GUI:**
- Выбор файлов через диалоговое окно (изображения или PDF)
- Настройка параметров распознавания (размеры символов, пороги, пробелы)
- Отображение прогресса обработки
- Просмотр результата в текстовом поле
- Копирование результата в буфер обмена
- Сохранение результата в файл
- Строка состояния с информацией о процессе

**Параметры в GUI:**
- Мин. высота символа (по умолчанию: 15)
- Мин. высота строки (по умолчанию: 50)
- Порог строк (по умолчанию: 70)
- Размер пробела (по умолчанию: 50)
- Масштаб для PDF (по умолчанию: 4.166)
- Номер страницы PDF (по умолчанию: 1)
- Опция сохранения промежуточных результатов

### Вариант 2: Распознавание изображения (main.py)

Для распознавания текста из изображения (PNG, JPG и др.):

```bash
python main.py
```

После запуска:
1. Введите имя файла изображения (например, `page.png`)
2. Результат будет сохранен в файл `result.txt`

**Пример:**
```bash
python main.py
# Введите имя файла: my_image.png
# Результат сохранится в result.txt
```

### Вариант 3: Распознавание PDF (main_with_pdf.py)

Для распознавания текста из PDF-файла:

```bash
python main_with_pdf.py
```

После запуска:
1. Откроется диалоговое окно для выбора PDF-файла
2. Введите номер страницы для распознавания
3. Выберите, сохранять ли промежуточные результаты (1 - да, 0 - нет)
4. Результат будет сохранен в папке `<имя_файла>/page<номер>/text.txt`

**Примечание:** Перед запуском убедитесь, что пути к файлам `machine.h5` и `predictions.txt` указаны корректно в коде (строка 288).

## ⚙️ Настройка параметров

В файле `main.py` можно изменить параметры распознавания:

- `min_h=15` — минимальная высота контура символа
- `max_h=700` — максимальная высота контура
- `max_w=400` — максимальная ширина контура
- `space=50` — размер пробела между словами
- `threshn=70` — порог для объединения символов в строки

## 🎯 Обучение модели

Для обучения собственной модели используйте `model.py`:

```bash
python model.py
```

Требования к данным:
- Изображения должны быть размером 56x56 пикселей
- Структура папок: `cnn/train/<класс>/` и `cnn/val/<класс>/`
- После обучения модель можно сохранить как `machine.h5`

## 🔍 Особенности обработки

Приложение выполняет следующую предобработку изображений:
1. **Киноварь в черный** — преобразование красных символов в черные
2. **Бинаризация** — перевод в черно-белый формат с использованием порога Оцу
3. **Морфологические операции** — эрозия и дилатация для улучшения качества
4. **Нормализация размера** — приведение всех символов к размеру 56x56

## ⚠️ Известные ограничения

- Точность распознавания зависит от качества исходного изображения
- Возможны ошибки при разделении слипшихся символов
- Требуется ручная проверка результатов для критически важных задач
- Модель обучена на конкретном документе, для других источников может потребоваться дообучение
