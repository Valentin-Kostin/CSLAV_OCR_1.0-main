# CSLAV_OCR - Оптическое распознавание церковнославянских текстов

## Описание проекта
CSLAV_OCR — это приложение для оптического распознавания символов (OCR), специально разработанное для распознавания церковнославянских текстов. Проект включает нейросетевую модель, обученную на 49 классах символов, включая основную кириллицу, старославянские буквы и диакритические знаки.

## Возможности
- ✅ Распознавание церковнославянских текстов из изображений (JPG, PNG, TIFF)
- ✅ Распознавание текста из PDF-документов
- ✅ Обработка киновари (красных символов)
- ✅ Поддержка диакритических знаков
- ✅ Графический интерфейс пользователя (GUI)
- ✅ Экспорт результатов в UTF-8
- ✅ Исправлена поддержка кириллических путей в Windows

## Системные требования
- Python 3.8 или выше
- pip (менеджер пакетов Python)
- Windows/Linux/macOS

**Важно:** Для корректной работы с кириллическими путями в Windows используется специальный метод загрузки изображений через `numpy.fromfile()` + `cv2.imdecode()`.


### 2. Создание виртуального окружения (рекомендуется)
```bash

source venv/bin/activate
```

### 3. Установка зависимостей
```bash

```

**Файл `requirements.txt` содержит:**
```

opencv-python>=4.5.0
tensorflow>=2.16.0
PyMuPDF>=1.19.0

```

**Примечание о Keras:** Начиная с TensorFlow 2.11, Keras встроен непосредственно в пакет TensorFlow. Отдельный пакет `keras` больше не требуется.

## Параметры настройки

- Выбор файла через диалог

## Особенности обработки

### Предварительная обработка изображений:
1. **Удаление киновари** - преобразование красных символов в черные
2. **Бинаризация** - адаптивное пороговое преобразование
3. **Морфологические операции** - удаление шумов, эрозия
4. **Нормализация размеров** - приведение символов к размеру 56x56 пикселей

### Архитектура нейросети:
- Сверточная нейронная сеть (CNN)
- 49 классов символов
- Входной размер: 56x56x3
- Поддержка старославянских букв и диакритических знаков

## Форматы входных данных
- **Изображения:** JPG, PNG, TIFF, BMP
- **Документы:** PDF (через PyMuPDF)

## Форматы выходных данных
- Результаты сохраняются в текстовом формате (.txt)
- Кодировка: UTF-8
- Возможность копирования в буфер обмена (GUI)

## Известные ограничения
- Точность распознавания зависит от качества исходного изображения
- Модель лучше всего работает с текстами, близкими по стилю к обучающей выборке
- Некоторые редкие символы могут распознаваться с меньшей точностью
- GPU не поддерживается на нативной Windows для TensorFlow >= 2.11 (требуется WSL2 или TensorFlow-DirectML)

## Сообщения лога и предупреждения

При запуске вы можете увидеть следующие предупреждения (они не влияют на работу):

- **oneDNN custom operations** - информирование о использовании оптимизаций CPU
- **UserWarning about `input_shape`** - рекомендация по использованию Input layer в Sequential моделях
- **Argument `decay` is no longer supported** - параметр decay игнорируется в новых версиях Keras
- **TensorFlow GPU support** - информация об отсутствии поддержки GPU на Windows
- **Compiled metrics** - предупреждение при загрузке сохраненной модели

Эти предупреждения можно игнорировать - приложение работает корректно.

## Логирование и отладка

Проект включает встроенную систему логирования для упрощения отладки:

### Файл лога
Все логи сохраняются в файл `csalv_ocr.log` в директории запуска приложения.

### Уровни логирования
- **DEBUG** - детальная информация для разработчиков (загрузка файлов, параметры обработки)
- **INFO** - общая информация о ходе работы (найденные символы, строки)
- **WARNING** - предупреждения, не критичные для работы
- **ERROR** - ошибки с трассировкой стека

### Просмотр логов
```bash
# Просмотр последних строк лога в реальном времени
tail -f csalv_ocr.log

# Поиск ошибок в логе
grep "ERROR" csalv_ocr.log

# Просмотр полного лога
cat csalv_ocr.log
```

### Настройка уровня логирования
В файле `logger_config.py` можно изменить уровень логирования:
```python
logger = setup_logger(level=logging.DEBUG)  # Максимальная детализация
logger = setup_logger(level=logging.INFO)   # Стандартный режим
logger = setup_logger(level=logging.WARNING) # Только предупреждения и ошибки
```

### Логирование в GUI
В графическом интерфейсе ошибки отображаются в диалоговых окнах, а детальная информация записывается в лог-файл. Консоль показывает только предупреждения и ошибки (уровень WARNING и выше).

## Решение проблем

### Ошибка чтения файла с кириллическим путем
Если вы получаете ошибку вида `can't open/read file: check file path/integrity`, убедитесь, что используете последнюю версию проекта. В обновленной версии `ocr_utils.py` исправлена проблема с кириллическими путями в Windows через использование `numpy.fromfile()` + `cv2.imdecode()`.

### Проблемы с установкой TensorFlow
```bash
# Попробуйте установить конкретную версию
pip install tensorflow==2.16.0

# Или используйте TensorFlow-DirectML для GPU на Windows
pip install tensorflow-directml
```

### Ошибки импорта keras
В современных версиях TensorFlow (>=2.11) используйте:
```python
from tensorflow.keras import ...
```
вместо отдельного импорта `import keras`.
